# 圣诞快乐 · 粒子炫酷版

纯 Python + pygame 实现的粒子版圣诞互动程序：开场粒子拼出「圣诞快乐」，随后汇聚成 3D 自转粒子圣诞树（树上缠绕发光粒子彩带、树顶五角星），再展开完整圣诞场景（雪人、房子、礼物盒、月亮、雪地、粒子烟花），配圣诞音乐，支持鼠标键盘交互。

![粒子版预览](%E7%B2%92%E5%AD%90%E7%89%88%E9%A2%84%E8%A7%88.png)

## 两种运行方式

### 方式一：直接用 exe（推荐，免安装）
双击 `粒子圣诞快乐.exe` 即可运行，无需安装 Python 或任何环境。

> 说明：exe 由 PyInstaller 单文件打包，首次启动需 5~10 秒；个别杀毒软件会对未签名 exe 误报，添加信任即可。

### 方式二：用 Python 运行源码
1. 安装 Python 3（安装时勾选 `Add python.exe to PATH`）
2. 安装依赖：
```bash
pip install pygame
```
3. 运行：
```bash
python christmas_particles.py
```

IDE 里运行：PyCharm / IDEA 新建项目，把 `christmas_particles.py` 放进项目，解释器选 `python.exe`，右键 `Run`。

## 操作说明

| 操作 | 功能 |
| --- | --- |
| 鼠标移动 | 粒子避让鼠标 |
| 点击 / 按住左键 | 放烟花 / 跳过开场 |
| 空格 | 暂停或继续音乐 |
| ↑ / ↓ | 调节音量 |
| C | 切换配色（霓虹 / 冰蓝 / 暖金 / 圣诞红） |
| A | 开关自动烟花 |
| F | 手动放一发烟花 |
| R | 重播 |
| S | 截图 |
| H | 显示/隐藏提示 |
| ESC | 退出 |
